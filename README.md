# Wealth Path: Net Worth Tracker

## Overview

Wealth Path: Net Worth Tracker is a personal finance app that helps users track their net worth, manage assets and debts, and plan for financial independence through interactive charts, financial projections, and an intuitive interface. I contributed to the development and promotion of the app by testing its features, evaluating its functionality, and providing feedback on the user experience. Afterwards, I created promotional videos to showcase the app's features and support its marketing efforts.


## Tools Used
