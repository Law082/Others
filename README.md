# Wealth Path: Net Worth Tracker

Wealth Path is a personal finance app that helps users track their net worth, manage assets and debts, and plan for financial independence through interactive charts, financial projections, and an intuitive interface.

## Overview

I contributed to the development and promotion of the Wealth Path app by testing its features, evaluating its functionality, and providing feedback on the user experience. Afterwards, I created promotional videos to showcase the app's features and support its marketing efforts.

## Tools Used

- Canva
- Renderforest
